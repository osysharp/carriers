# osysharp/carriers

Osy# packages, one per folder. Each folder is a package of its own, with its own README, tests and releases (tagged `<folder>/v<version>`).

| Folder | Package | What it is |
|---|---|---|
| [`postnord/`](postnord/) | `Osysharp.Carriers.PostNord` | PostNord parcels — booking with a PDF label, track & trace, service points, and a delivery provider. |
| [`sendcloud/`](sendcloud/) | `Osysharp.Carriers.Sendcloud` | Sendcloud — many European carriers behind one API: labels, customs, tracking, returns, pickups, and a delivery provider. |
| [`shippo/`](shippo/) | `Osysharp.Carriers.Shippo` | Shippo — USPS, UPS, FedEx and DHL Express behind one API: labels, customs, returns, tracking, and a delivery provider. |
